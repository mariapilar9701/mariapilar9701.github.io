Meet The Machine

About Our Project

Our machine identifies and categorizes an image using probability.

The categories for our machine learning project were chosen to match both the theme of our website’s design and also some of the content concepts. A ghost was chosen as a reference to the “Ghost in the Machine” film that inspired the name of our website. The sun and shooting stars are a representational mix of the background design of the website and electricity which the machine requires. The cloud is a reference to the technological cloud which is ever present in our daily lives, especially as students.

Our Process

While our process was mostly straightforward, we did encounter some bumps along the way.

The First Attempt

To begin, we selected a theme for our project that would fit our previous project. Based on that theme, we came up with the categories: star, shooting star, ghost, and moon. In order to give the machine varying samples to learn from, we decided to both draw in more than one style along with only some images using color.

⇩

Once we had our physical sketches ready, we decided to take pictures from varying angles with the idea in mind that the machine would learn to identify the image without requiring the perfect straightforward position and lighting.

⇩

With all of the sample images were prepared, we used Google Creative Lab’s Teachable Machine to train a model based on each of the categories.

⇩

While we tested our trained model, we noticed that the “ghost” category was not as accurate as we had expected. Our project would require more examples for the learning process.

Our Process

Trying Again

At this point, we had four categories which had equal numbers of samples for the machine to learn from. We decided to create a new category that would intentionally have significantly less sample data.

We created the “cloud” category and with only one-third of the samples compared to the other categories.

⇩

We also added some more samples for the "ghost", which had low accuracy during the first attempt.

⇩

With the newly added sample data, we retrained the machine and were satisfied with its performance.

⇩

Exporting the files from the Teachable Machine website and integrating them into our page design was a very simple process. After a few tweaks to add a stop button and fix some stylistic choices, it was ready to go.

Try it yourself!

Instructions - just follow these simple steps:

  1. Prepare your "test object" - a drawing of a moon, shooting star, sun, or cloud.
  2. Click the "Start" button. Testing this process requires access to a webcam.
  3. Hold up your sketch to the camera.
  4. Optional: You can click the "Stop" button to pause the webcam. Simply click "Start" again to resume.
